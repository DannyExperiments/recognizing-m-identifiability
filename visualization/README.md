# When the pivot certifies a factor

Extract the ZIP and open index.html in a browser. It runs offline. Rotate the factor graph with the slider or by dragging. The worked graph has two latent factors and five observed vertices. The pivot v certifies h when two base paths are possible and the augmented sides still have maximum matching size two.

Switch on latent s to give c and d a second center. Now all three augmented paths can be matched, so v fails the test. Read the explanation for why no first move is possible anywhere in this enlarged graph.

The rotating GIF shows the two-factor case from a 3D camera. With existing Python and Pillow, run python3 visualization/render.py to regenerate it. Fonts can affect GIF bytes.
